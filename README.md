## Installation

Themes can be installed directly from the Forge Panel admin area with live previews:

**Admin → Plugins → Theme Store → Preview & Install**

### Requirements
- Node.js 22+
- Yarn (via Corepack or npm)

```bash
curl -sL https://deb.nodesource.com/setup_22.x | sudo -E bash -
sudo apt install -y nodejs
sudo corepack enable
```
